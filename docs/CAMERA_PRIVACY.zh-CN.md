# 摄像头隐私审计

已审核 MaixCam 应用的全部网络出口。

## 审计结果

- 不存在 HTTP 或 HTTPS 客户端。
- 不存在 MQTT、WebSocket客户端、云服务SDK、分析统计、遥测、上传、`curl`或`wget`代码。
- 摄像头画面仅在设备本地编码，并通过局域网 TCP 8080端口提供 MJPEG串流。
- 视频服务只绑定摄像头当前局域网IP，不再绑定全部网络接口。
- `wifi_manager.py`连接 `192.168.8.1`的UDP socket只用于让操作系统返回本机应使用的源IP，不会发送摄像头数据。
- WiFi密码只保存在设备的 `/root/wrobot_wifi.json`，文件权限仅限所有者，视频服务不会返回该文件。

## 局域网访问边界

MaixCam 的8080端口目前没有登录认证，因此同一可信局域网内能够访问摄像头IP的设备可以观看视频。程序不会配置路由器端口转发，也不会把视频上传到互联网。不要在路由器上转发8080端口，也不要把摄像头接入不可信公共WiFi或公开反向代理。
