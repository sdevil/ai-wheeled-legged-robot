# 诊断系统

主板提供只读的 `GET /api/diagnostics` 运行时诊断接口。

诊断快照包含系统内存、复位原因、电池、WiFi、摄像头、运动参考值、追踪输入与输出、OTA 状态及最近 24 条诊断事件。事件缓冲区使用固定内存，不会在实时控制循环中动态分配内存。

进入 **设置 > 高级维护 > 诊断**，可以手动刷新、开启实时更新或复制完整 JSON 报告。实时更新默认关闭，避免产生不必要的网络负载。

调查追踪问题时，应在目标锁定后复制一次报告，并在问题发生后立即再复制一次。重点字段包括 `tracking.state`、`confidence`、`error_x`、`error_y`、`error_z`、`yaw_command`、`drive_command`、摄像头角度和事件时间线。

MaixCam 连接时不建议使用 USB 串口监视，因为两者共用主板 UART0。
